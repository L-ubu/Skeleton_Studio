02What you get

◆ Flow editor

Drag-and-drop chains: gesture triggers wired to action blocks — keypress, mouse click, shell command, macro.

◆ Live camera feed

Real-time hand skeleton overlay with gesture detection and per-frame confidence tracking.

◆ Skeleton-only mode

Black out the camera feed and show only the hand skeleton with S. Privacy-friendly demos.

◆ Mouse mode

Control your cursor with your hand via M. Yes, it feels like the future.

◆ Global hotkey

Cmd+Shift+G toggles gesture recognition system-wide — on for the demo, off for the typing.

◆ Save & load projects

Export gesture configurations, share them, import someone else's setup in one click.

04Why it exists

The decisions worth knowing about, written down.

Gesture control shouldn't need code

The engine is powerful, but "edit a YAML and restart" kills the magic. The studio makes it a drag, a drop, and a wave of the hand.

Live sync, no restarts

Changes in the UI push instantly to the running engine over WebSocket. Tweak a threshold and test it in the same second.

Built on a real engine

Everything runs on Skeleton_Engine — the CLI core. The studio is the friendly face, not a rewrite.
